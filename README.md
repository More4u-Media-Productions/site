# More4u Productions Website v2

A self-hostable, framework-free More4u Productions website.

Included:
- Main company homepage
- About / founder page
- Updates hub + individual posts
- Echo project page
- Dayline project page, marked IN DEVELOPMENT
- Services
- Contact
- Responsive navigation
- Mobile layout
- Scroll/reveal effects
- SEO/Open Graph metadata
- User-provided More4u and Echo logos

## Before launch
1. Replace the placeholder contact email in `index.html`.
2. Add the public Echo URL in `projects/echo.html`.
3. Add real screenshots/assets as projects grow.
4. Upload the contents of this folder to your web host.
5. Point your website DNS record to the host. Keep ImprovMX's mail records intact.

No framework or build step is required.
