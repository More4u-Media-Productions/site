SEPTEMBER 2026 · RELEASE

Dayline opens its prototype for feedback.

We are releasing an early version because the best way to learn what matters is to let people actually use it.

Dayline is currently available as a prototype built with Lovable. It brings together the ideas behind schedules, tasks, contacts, reminders and everyday organization in a version people can try today.

This is not the final hand-built product. We released the prototype intentionally so people can give us honest feedback before we build the official version ourselves.

If you try Dayline and something feels useful, confusing, incomplete or unnecessary, that feedback can shape what comes next.
